# Color Coded Combinators

Give any combinator a custom color using a selection tool.

<!-- TODO: screenshot of colored combinators -->

## Features

- Color tool shortcut works on all combinators
- Select to paint, alt-select to clear the color
- Empty selection opens the color picker (RGB sliders with a preview)

## Usage

1. Click the shortcut or press `C` to get the tool
2. Click with nothing selected to choose a color
3. Drag over combinators to apply it; alt-drag to clear it

## Development

```bash
git clone --recursive https://github.com/CTNOriginals/ColorCodedCombinators.git
```

- Copy `.env.example` to `.env` and fill in the paths
- Run `make help` to see the available commands
